## Prérequis

Créer et activer un environnement virtuel `.venv` :

```bash
# Création de l'environnement virtuel
python -m venv .venv

# Activation sur Windows (PowerShell)
.\.venv\Scripts\Activate.ps1

# Activation sur Windows (CMD)
.venv\Scripts\activate.bat

# Activation sur macOS / Linux
source .venv/bin/activate
```

Installer les librairies nécessaires avant de lancer le projet :

```bash
pip install pandas xmltodict
```

## Comment lancer le projet

```bash
python main.py
```
